

# Image Processing Using OpenCV

A Python-based image processing project developed using OpenCV and other scientific computing libraries.

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Google Colab

## Project Features
- Grayscale Conversion
- Image Resizing
- Image Cropping
- Gaussian Blurring
- Edge Detection
- Image Thresholding
- Image Rotation
- Image Flipping
- Brightness and Contrast Adjustment
